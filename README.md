# Project's description

The A project is a Java development **multi-applications** project which entirely relies on a **minimalist framework** (the a framework). Its goal is to enable applications development in a scalable and flexible way, with reusable components.

# First step

Compile de src folder by including the lib folder's JARs in the classpath.
Launch the core Main class : *a.core.gus.gyem.GyemMain*.
In order to start the main application and learn more about the A project, add the following argument : *config=gus.appli1*

# Reference command lines

```
java a.core.gus.gyem.GyemMain config=gus.appli1
```

# To go further

Once the gus.appli1 has been launched, all the required documentation can be found inside its tabs.
